# Governance

## Current model

Open Retail Scanner is governed as an independent open-source project. Maintainers merge changes, publish releases, manage security reports, and protect benchmark integrity.

SafeEat is the first pilot integrator. Pilot status provides structured feedback and a real-world validation environment, but does not grant ownership of the project, privileged access to private user data, or authority to bypass public scope, security, benchmark, and compatibility gates.

## Decision process

- Routine implementation follows reviewed issues and pull requests.
- Changes to scope, formats, privacy behavior, benchmark gates, licensing, comparison policy, or public claims require a written decision record.
- Security, privacy, and legal reviewers may block releases in their domain until a qualified human review is recorded.
- Agent recommendations do not constitute human approval.
- Application-specific requirements are evaluated as proposals; no pilot application may silently redefine the general SDK contract.

## Roles needed before a supported release

- product owner;
- technical maintainer;
- backup release maintainer;
- benchmark/corpus steward;
- security contact;
- legal/licensing reviewer.

## Project maturity

Until a stable release policy is adopted, all APIs are experimental and no compatibility or support SLA is promised.

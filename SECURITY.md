# Security policy

## Supported versions

No production version is currently supported. The repository is in an experimental benchmark phase.

## Reporting

Do not open a public issue for a vulnerability, privacy leak, corpus exposure, or licence incident. Use GitHub private vulnerability reporting once enabled for the repository. Until then, contact the repository owner privately through their verified GitHub profile.

Do not include real frames, barcode values, product identities, personal data, or exploit data that is unnecessary to reproduce the problem.

## Response objectives

Maintainers should acknowledge a report within five working days, classify affected versions and data, and publish remediation or containment guidance. These are best-effort objectives until a funded security owner is named.
